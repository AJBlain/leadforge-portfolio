# LeadForge Changelog

## 1.0.0 — 2026-11-03
- Rebranded all pages, window title, icons, copy and export names as LeadForge, with an independent midnight/teal visual system.
- Added Product Overview describing features, architecture and explicit limits for evaluators.
- Removed experimental remote research UI, backend routes, script dependency and embedded service credential; no hosted AI runtime is required.
- Replaced embedded personal outreach signature with an optional user-configured browser-local value.
- Preserved existing saved lead storage and installed a copy-only legacy key migration for Reddit/coverage/excluded-owner metadata.
- Added native Windows x64 launcher and executable per-user installer, shortcuts and uninstaller, plus source build instructions.
- Added GitHub-ready README, technical case study, automated tests and Windows release CI workflow.
- Preserved current Reddit region batches, date review queue, dedupe, scoring, property workspaces and pipeline behavior.

## Compatibility baseline
Built on the v5.1 application logic. Earlier changes included six regional Reddit batches, date-verification queue, saved-lead follow-up workflow, public GIS filtering, and normalized community imports. This v1.0 release is a **branding and packaging milestone**, not a claim that every public GIS search endpoint works in all DFW jurisdictions.
