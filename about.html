ENGINEERING PORTFOLIO · v1.0

Research. Rank. Act.

A local-first real estate intelligence workbench built to turn open property records and human-reviewed community research into a structured, traceable lead workflow.

Property intelligence

Public ArcGIS parcel queries, structured filters, ownership screening, source links, and map-based exploration.

Decision support

Explainable, rule-based opportunity and vacancy-signal scores. Estimates are distinguished from verified property facts.

Lead operations

Persistent lead records, deduplication, pipeline stages, follow-up scheduling, archived records, and CSV exports.

AI-assisted discovery

Regional Reddit research prompts for use with ChatGPT, with a structured import and manual date-verification queue. No unauthorized scraping.

Defensive engineering

Visible data-save failures, bounded batch processing, response caching, source-failure reporting, and regression tests.

Privacy by default

No hosted CRM, no automatic outreach, no embedded API secrets, and user contact details configured locally.

Architecture & limitations

Stack: vanilla JavaScript, HTML, CSS, PowerShell, ArcGIS REST, Leaflet, browser localStorage, and a Go-based Windows launcher/installer. The app serves its UI locally at 127.0.0.1:8765.

How it works: local search UI → PowerShell service → approved public GIS endpoints → normalization/filtering → interpretable scoring → human-managed lead pipeline.

What isn't automated: Reddit discovery uses user-operated ChatGPT prompts and manual JSON import, not an unattended Reddit crawler. Property and vacancy estimates are screening signals, not verified listing/vacancy status. Public source coverage and availability may vary by region.

Data: saved leads stay in the active browser profile and are not uploaded by LeadForge. No user credentials are required for basic operation.

Evaluation: see README.md, ARCHITECTURE.md, TEST_PLAN.md, and docs/PORTFOLIO_CASE_STUDY.md in the source distribution.
